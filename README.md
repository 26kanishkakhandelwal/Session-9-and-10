# 🌐 Personal Portfolio — Session 9 & 10

> A personal portfolio website built from scratch using HTML, CSS, and JavaScript.

This project was created during **Session 9 & 10** as a practical application of frontend web development concepts.

The idea was simple: take basic web technologies and use them to create a website that represents **me, my skills, my work, and my journey as a developer**.

---

## ✨ What This Project Is

This is a responsive personal portfolio website designed to bring different parts of my profile together in one place.

It includes sections for:

* 👋 Introduction
* 📖 About Me
* 🛠️ Skills
* 📂 Projects
* 📞 Contact
* 🌙 Theme switching

The project focuses on creating a clean interface while also adding interactive functionality using JavaScript.

---

## 🎨 Highlights

### 🧑‍💻 Personal Profile

A dedicated introduction section that gives visitors a quick idea about who I am and what I do.

### 📖 About Me

A short overview of my background, interests, and learning journey.

### 🛠️ Skills

A section highlighting the technologies and skills I am currently working with.

### 📂 Projects

A space to showcase projects and practical work.

### 🌙 Light / Dark Mode

The website includes theme-switching functionality, allowing the user to change between light and dark appearances.

### 📱 Responsive Design

The layout is designed to adapt to different screen sizes, making the portfolio usable across desktops, tablets, and mobile devices.

### ⚡ JavaScript Interactivity

JavaScript is used to add functionality and make the website more interactive instead of keeping it completely static.

## ▶️ How to Run

No complicated setup is required.

### Option 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

That's it. 🚀

### Option 2 — Clone Using Git

```bash
git clone https://github.com/26kanishkakhandelwal/Session-9-and-10.git
```

Then open the folder:

```bash
cd Session-9-and-10
```

Open `index.html` in your preferred browser.
